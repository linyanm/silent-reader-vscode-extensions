# Support

If you run into a bug, have a feature request, or want to discuss
improvements for Silent Reader, use one of the following channels:

- Issues: <https://github.com/linyanm/silent-reader-vscode-extensions/issues>
- Repository: <https://github.com/linyanm/silent-reader-vscode-extensions>

When reporting a bug, include:

- VS Code version
- Silent Reader version
- Operating system
- Steps to reproduce
- A sample TXT file or title format if the problem is chapter detection
